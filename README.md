# Agentic AI Demo Project Website

This is a static GitHub Pages-ready project management website for the Agentic AI Demonstration Project.

## What is included

- Public project overview and problem statement
- Three pilot tracks: institution-facing, student-facing, and faculty-facing
- Interactive pilot filter
- Pilot track detail selector for Pilot 1, Pilot 2, and Pilot 3
- Project workboard with add, edit, delete, status, pilot assignment, due/milestone, details, and multiple assignees saved in the browser
- Roadmap, success outcomes, guide sections, governance, RACI snapshot, and rough budget
- Expanded RACI page aligned to the Demonstration Project SOP
- MVP and Go Live budget toggle
- Downloadable source project documents in `docs/`

## Publish on GitHub Pages

1. Commit this folder to the GitHub repository.
2. In the repository settings, enable GitHub Pages.
3. Set the Pages source to the branch and folder that contains this project.
4. Open the published Pages URL.

For a repository root site, move the contents of this folder to the repo root. For a subfolder site, keep this folder and set Pages accordingly.
